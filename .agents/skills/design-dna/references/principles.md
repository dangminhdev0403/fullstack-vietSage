# Principles

1. **Readable hospitality UI: normal content is at least 16px; metadata is at least 14px.**
2. **Premium means quiet hierarchy and generous rhythm, not tiny type or ornamental clutter.**
3. **Guest, staff, owner, and admin surfaces share tokens while preserving task-appropriate density.**
4. **Reuse existing UI primitives; do not create local variants for visual taste alone.**
5. **Stable loading, empty, error, and success states must preserve layout and explain the next action.**
