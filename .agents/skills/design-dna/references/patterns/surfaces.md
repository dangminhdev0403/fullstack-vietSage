# Surface Patterns

## Public/marketing
Strong hierarchy and brand expression, readable measure, restrained effects, no decorative motion that shifts content.

## Operational workspace
Task-first hierarchy, stable shell, explicit permissions and state, comfortable default density.

## Authentication
Visually continuous with the product; large labels/inputs/actions; credential ownership remains at the canonical auth boundary.

## Responsive
Collapse grids before shrinking type. Convert wide tables to deliberate scroll/card patterns. No horizontal page scroll.
