# Semantics

## Typography
- Display: product/section identity only.
- Heading: clear task hierarchy; no decorative all-caps paragraphs.
- Body: default reading and operational content, 16px minimum.
- Metadata: secondary dates, IDs, helper text, 14px minimum.
- Label/action: 14px only for compact secondary controls; primary controls use 16px.

## Color
Primary text carries content; muted text remains readable. Accent indicates action. Success/warning/error roles never substitute for each other and never rely on color alone.

## Spacing and elevation
Related content uses compact spacing; sections use section spacing. Cards group real concepts, not every paragraph. Overlays alone receive strong elevation.
