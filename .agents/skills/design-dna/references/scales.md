# Scales

## Responsive
Use Tailwind defaults. Verify 320, 390, 768, 1024, 1440, and 1920px; avoid component-specific breakpoints unless content proves the need.

## Grid
Fluid mobile single-column; structured desktop grid; no fixed widths that force horizontal page scroll.

## Density
One comfortable default. Data tables may be compact, but readable type floors remain unchanged.

## Color modes
Light, warm surfaces are canonical. Dark overlays only for modals/navigation where context requires them.

## Stability
Reserve geometry for loading/empty/error states. Font swap, wrapping, long translations, and async content must not overlap controls or move primary navigation unexpectedly.
