# Core Components

## Buttons and inputs
Primary actions: 16px text, 44px minimum touch height, explicit focus/loading/disabled state. Inputs inherit body font and never zoom on mobile.

## Cards
Cards use semantic surfaces, consistent internal padding, and one radius tier chosen by prominence. Hover lift is optional, restrained, and pointer-only.

## Navigation
One active destination per level. Labels remain readable and wrap/truncate deliberately for translated text.

## Tables and status
Tables preserve 14px minimum metadata and 16px important values. Status includes text/icon, not color alone.
